# Divya Sri R - Portfolio

## Open it
Unzip, then double-click `index.html`. Everything it needs is inside that file, so it works with no setup.

## Put it online (free)
- Netlify: drag the whole `Divya_Sri_R_Portfolio` folder onto app.netlify.com/drop
- GitHub Pages / Vercel: upload the folder contents

## What is in the folder
- `index.html`   the finished site (styles and scripts built in)
- `assets/`      resume PDFs used by the Download resume buttons
- `source/`      the same site split into index.html, css/style.css and js/main.js for editing

## Easy edits
- Colours: top of `source/css/style.css` (--cyan, --violet, --amber, --bg)
- LinkedIn, project data, stage text: `source/js/main.js`
- Text content: `source/index.html`
After editing the source, copy the CSS and JS back into one index.html, or just edit `index.html` directly.

Fonts load from Google Fonts when online and fall back to system fonts offline.
Project demo numbers are sample data, labelled as such on the page.
